# Sentiment Analysis of Social Media Data using Power BI

## Task Description
Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards specific topics or brands.

## Dataset
Twitter sentiment dataset containing tweet text, topic, and sentiment labels.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Visualizations
- Sentiment distribution (Pie Chart)
- Sentiment comparison (Bar Chart)
- Topic-wise sentiment analysis (Stacked Column Chart)
- Interactive slicer for topic filtering

## Key Insights
- Positive sentiment dominates across most topics.
- Neutral sentiment indicates mixed opinions.
- Negative sentiment is comparatively lower.
